# Lugo — archive de recherche et guide de développement

Ce dossier conserve les audits préparatoires et la synthèse fonctionnelle pour faire évoluer Lugo comme plateforme d’intelligence FiveM pour développeurs et agents IA.

## Archives des audits

- [`agent-fivem-ecosystem.md`](agent-fivem-ecosystem.md) — écosystème FiveM, NUI, State Bags, OneSync, frameworks, SQL et runtime.
- [`agent-security-reliability.md`](agent-security-reliability.md) — sécurité, fiabilité, graphes de ressources, diagnostics et CI.
- [`agent-mcp.md`](agent-mcp.md) — ergonomie MCP, outils sémantiques pour agents et workflows d’édition sûrs.
- [`agent-human-developer.md`](agent-human-developer.md) — expérience LSP/VS Code et fonctionnalités de développement humain.

## Guide

- [`suggestions.md`](suggestions.md) — guide consolidé, détaillé et organisé par domaines.
- [`annexes/architecture.md`](annexes/architecture.md) — modèle sémantique cible et réutilisation de l’existant.
- [`annexes/mcp-contract.md`](annexes/mcp-contract.md) — contrat MCP cible pour les agents.
- [`annexes/implementation-method.md`](annexes/implementation-method.md) — méthode de livraison, tests et critères d’acceptation.
